# Product Sense

## User Value

The product promise is not "remember everything." It is "remember the right things, under user control, and make the phone's agents more useful across apps without leaking personal context."

## Target Users

- Power users who want cross-app continuity and automation.
- Mobile OS or assistant teams building system-level personal AI.
- App developers who need safe access to user-approved memory views.

## Product Principles

- User control is a feature, not a settings afterthought.
- Memory should be explainable at the moment it affects an answer or action.
- Passive collection must be visibly bounded and easy to pause.
- Third-party apps receive projections, not raw global memory.
- Procedural automation requires confirmation before autonomous execution.

## Success Signals

- Higher task completion rate from memory-assisted interactions.
- Lower repeated user explanation across apps and sessions.
- Low false-memory and stale-memory incident rate.
- High user correction success rate.
- Demonstrable deletion propagation across indexes and summaries.
